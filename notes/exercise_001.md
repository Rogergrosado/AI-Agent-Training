## 1. Objective

The objective of this exercise was to configure and execute a Large Language Model locally using Python and Ollama, establishing a foundation for future AI agent development.

## 2. Technologies Used

- Python 3.12
- Ollama
- Qwen2:1.5b
- Windows PowerShell
- Python virtual environment
- Requests library

## 3. Development Process

1. Installed and verified Ollama.
2. Downloaded and successfully executed the Qwen2:1.5b model.
3. Created a dedicated Python virtual environment.
4. Installed the required Python dependencies.
5. Verified communication with the local Ollama API.
6. Created the Python script `first_local_llm.py`.
7. Executed the script and received a generated response.

## 4. Practical Application — Logistics

The model was asked:

"Explain how AI agents can help logistics companies."

Its response discussed several potential applications, including route optimization, predictive maintenance, real-time shipment monitoring, inventory forecasting, and supply chain visibility.

These examples demonstrate how language models can support research and analysis related to logistics operations.

## 5. Results

The Python application successfully communicated with the locally running language model and displayed its generated response in PowerShell.

This exercise confirmed that my laptop can execute a small local language model without requiring a cloud inference service.
